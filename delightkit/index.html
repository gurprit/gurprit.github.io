03 / PICK YOUR IMPLEMENTATION

Your stack. Your kind of delight.

Standalone JavaScript for any site. Optional components for React projects.

VANILLA JAVASCRIPT

No framework required.

The live examples above run on plain JavaScript and CSS. The free burst helper is ready to try right here. 

import { burst } from './src/delightkit-free.js';

const button = document.querySelector('#buy');
button.addEventListener('click', () => {
  burst(button, { amount: 24 });
});
Open the standalone free demo ↗
REACT + TYPESCRIPT

A component-sized celebration.

The full kit’s optional React components fit into your existing app. This is an integration example; the demos above use Vanilla JS. 

import { CelebrationButton } from './delightkit';

<CelebrationButton amount={20}>
  Add to basket
</CelebrationButton>

React is required only when using the React components.
